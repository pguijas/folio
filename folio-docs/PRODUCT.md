# Folio Docs

Folio Docs is an open-source documentation generator. Every page ships as HTML
for people and Markdown for agents, generated from source without importing it.

Its product boundary includes source parsing, guides, API reference, search,
themes, deployment, Markdown mirrors, `llms.txt`, and the authoring contract.
It does not own project planning or the git-backed board. Those belong to Folio
for Agents and enter a Docs site only through an explicit optional integration.

Version 0.3.0 is released independently as `folio-docs` and operated through
the shared `folio` command.
