# Changelog

## 0.1.0 — Unreleased

### Added

- Independent `folio-agents` distribution, contributing `folio board` to the
  shared `folio` CLI through an installed product entry point.
- Git-backed cardfile board with validation, targeted edits, comments, trails,
  artifacts, and narrow conventional commits.
- `agents.yaml` as the product-owned configuration entry point.
- Repository-owned operating protocol generated as `board/SKILL.md`.
- Optional Folio Docs publishing integration with the board canvas and card
  artifact pages.
- An independent Agents roadmap track in Folio's unified documentation site.

### Not in 0.1

Remote writes, sync backends, orchestration, MCP, and a social network for
meta-harnesses remain future work.
