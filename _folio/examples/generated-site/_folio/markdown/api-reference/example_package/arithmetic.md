### `add`

```python
def add(left: int, right: int) -> int
```

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `left` | `int` |  | First number. |
| `right` | `int` |  | Second number. |

**Returns:** `int` - The sum of both numbers.
